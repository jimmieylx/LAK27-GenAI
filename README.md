# GenAI–LA 2027

**Fourth International Workshop on Generative AI and Learning Analytics**  
*Artificial Agency, Agentic AI, and Learning Beyond Performance*

An accepted half-day, in-person pre-conference workshop at the **17th International Conference on Learning Analytics & Knowledge (LAK27)** in Recife, Brazil, **8 or 9 March 2027** (exact day pending).

This is a **standalone public GitHub repository** for the workshop website. It is separate from Lixiang Yan's academic portfolio.

## Website

https://jimmieylx.github.io/lixiangyan.github.io/

### Enabling publication

GitHub Pages must be enabled for this repository once by a repository administrator:

1. Open [Settings → Pages](https://github.com/jimmieylx/lixiangyan.github.io/settings/pages).
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Set **Branch: main**, **Folder: /(root)**, then **Save**.
4. GitHub will build and publish the `index.html` automatically. Subsequent commits publish new content.

The public URL above does not resolve until GitHub Pages has been enabled.
